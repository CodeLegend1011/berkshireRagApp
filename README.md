## 🧠 Project Overview

**Berkshire Hathaway RAG Intelligence** is a sophisticated Retrieval-Augmented Generation (RAG) application built with the **Mastra framework** — a cutting-edge TypeScript AI development platform. This system transforms decades of Warren Buffett's annual shareholder letters (2019-2024) into an intelligent, conversational agent that embodies his investment philosophy, analytical mindset, and communication style.

The application goes beyond simple document retrieval by implementing **semantic understanding**, **contextual memory**, and **philosophy-aware responses**. Whether you're researching Buffett's views on cryptocurrency, analyzing Berkshire's acquisition strategy, or exploring his thoughts on market timing, this RAG agent provides grounded, citation-backed insights drawn directly from primary sources.

### 🎯 What Makes This Different?

- **Philosophy Lens Agent**: A specialized sub-agent that interprets responses through the lens of Buffett's distinctive investment principles and tone
- **Reflection Memory System**: Persistent conversation intelligence that learns from each interaction
- **Hybrid Search Architecture**: Combines vector embeddings with SQL metadata filtering for precision retrieval
- **Source Transparency**: Every response includes AI-generated summaries of cited paragraphs with exact document attribution

## 🌟 Key Features

### 1️⃣ **Philosophy Lens Agent** 🎭
A specialized sub-agent that analyzes and reinterprets responses through Warren Buffett's distinctive investment philosophy. Using **semantic embedding clustering**, it ensures every answer reflects his principles of value investing, long-term thinking, and business fundamentals analysis.

### 2️⃣ **Reflection Memory System** 🧠
An intelligent memory layer that captures user intent, conversation context, and recurring topics across chat sessions. This creates a **personalized experience** where the agent remembers your interests and provides increasingly relevant responses over time.

### 3️⃣ **Hybrid Search Engine** 🔍
Combines the power of:
- **Vector Similarity Search**: Semantic understanding using 768-dimensional embeddings (text-embedding-004)
- **SQL Metadata Filtering**: Precise filtering by `year`, `company`, `topic`, and document type
- **Configurable Thresholds**: Similarity threshold of 0.75 ensures high-quality retrieval

### 4️⃣ **AI-Generated Source Summaries** 📝
Every cited paragraph includes a **concise TL;DR** generated by Gemini 2.5 Flash, making it easy to understand why specific sources were retrieved without reading full document sections.

### 5️⃣ **Analytics Endpoint** 📊
Access system intelligence through `/analytics`:
- **Top User Queries**: Most frequently asked questions
- **Response Latency**: Performance metrics across retrieval and generation
- **Retrieval Accuracy**: Effectiveness of vector search results
- **Memory Depth**: Conversation context retention statistics

### 6️⃣ **Mastra Playground UI** 🎮
Interactive chat interface at `/agents` featuring:
- Real-time streaming responses
- Source citation display with clickable references
- Conversation history visualization
- Agent configuration testing tools

### 7️⃣ **PostgreSQL + pgvector** 🗄️
Enterprise-grade vector storage powered by:
- **Neon Database**: Serverless PostgreSQL with automatic scaling
- **pgvector Extension**: Efficient similarity search with HNSW indexing
- **Hybrid Queries**: Combines vector operations with traditional SQL filtering

### 🔧 Core Components Explained

#### **Mastra Initialization (`src/mastra.ts`)**
The heart of the application where all Mastra primitives are configured:

```typescript
import { Mastra } from '@mastra/core';
import { PostgresAdapter } from '@mastra/pg';
import { berkshireAgent } from './agents/berkshire-agent';
import { ragWorkflow } from './workflows/rag-workflow';

export const mastra = new Mastra({
  agents: [berkshireAgent],
  workflows: [ragWorkflow],
  memory: {
    provider: new PostgresAdapter({
      connectionString: process.env.DATABASE_URL,
    }),
  },
  logger: { level: 'info' },
});
```

#### **RAG Workflow Creation**
Built using Mastra's `createWorkflow` and `createStep` APIs:

```typescript
import { createWorkflow, createStep } from '@mastra/core';

export const ragWorkflow = createWorkflow({
  name: 'berkshire-rag',
  steps: [
    createStep({
      id: 'retrieve-context',
      execute: async ({ input }) => {
        return await vectorSearchTool.execute({
          query: input.question,
          topK: 5,
          threshold: 0.75,
        });
      },
    }),
    createStep({
      id: 'generate-response',
      execute: async ({ context, input }) => {
        return await agent.generate({
          prompt: input.question,
          context: context.documents,
        });
      },
    }),
  ],
});
```

#### **Vector Search Tool Integration**
Seamless connection between Mastra agents and PostgreSQL pgvector:

```typescript
import { Tool } from '@mastra/core';
import { pgvector } from './config/database';

export const vectorSearchTool = new Tool({
  id: 'hybrid-search',
  description: 'Search Berkshire documents using vector similarity + metadata',
  inputSchema: z.object({
    query: z.string(),
    year: z.number().optional(),
    company: z.string().optional(),
    topK: z.number().default(5),
  }),
  execute: async ({ query, year, company, topK }) => {
    const embedding = await generateEmbedding(query);
    
    return await pgvector.query(`
      SELECT content, metadata, 
             1 - (embedding <=> $1) as similarity
      FROM documents
      WHERE ($2::int IS NULL OR metadata->>'year' = $2::text)
        AND ($3::text IS NULL OR metadata->>'company' ILIKE $3)
        AND 1 - (embedding <=> $1) >= 0.75
      ORDER BY similarity DESC
      LIMIT $4
    `, [embedding, year, company, topK]);
  },
});
```

#### **Context Reflection & Memory**
Persistent conversation intelligence using Mastra's memory system:

```typescript
import { ReflectionMemory } from '@mastra/memory';

export const conversationMemory = new ReflectionMemory({
  adapter: postgresAdapter,
  config: {
    maxDepth: 10,              // Remember last 10 interactions
    reflectionThreshold: 3,    // Reflect after 3 messages
    summaryLength: 150,        // Tokens for conversation summary
  },
});

// Automatic reflection after threshold
await conversationMemory.addMessage({
  role: 'user',
  content: userMessage,
  metadata: { topics: extractedTopics, intent: userIntent },
});
```

## 🧰 Setup Instructions

### Prerequisites

Before you begin, ensure you have:
- **Node.js**: Version 20.9.0 or higher
- **npm**: Version 9.0.0 or higher
- **PostgreSQL**: Access to a PostgreSQL database (local or cloud)
- **API Keys**: 
  - Google Gemini API key ([Get it here](https://makersuite.google.com/app/apikey))
  - OpenAI API key ([Get it here](https://platform.openai.com/api-keys))

### 🚀 Installation Steps

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/CodeLegend1011/berkshireRagApp.git
cd my-mastra-app
```

#### 2️⃣ Install Dependencies

```bash
npm install
```

#### 3️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```bash
cp .env.example .env
```

Update the `.env` file with your credentials:

```env
# Database Configuration (Neon DB)
DATABASE_URL="postgresql://neondb_owner:YOUR_PASSWORD@YOUR_HOST.neon.tech/neondb?sslmode=require"
PGVECTOR_DIM=768                        # Gemini embedding dimensions
PG_MAX_CLIENTS=10

# Google Gemini Configuration
GEMINI_API_KEY="your_gemini_api_key_here"
GEMINI_API_BASE="https://generativelanguage.googleapis.com/v1beta"

# OpenAI Configuration (for embeddings)
OPENAI_API_KEY="your_openai_api_key_here"

# Mastra Configuration
MASTRA_ENV=development
MASTRA_LOG_LEVEL=info
PORT=8080

# Model Configuration
DEFAULT_EMBED_MODEL="text-embedding-004"
DEFAULT_GEN_MODEL="gemini-2.5-flash"

# RAG Configuration
VECTOR_SIMILARITY_THRESHOLD=0.75
HYBRID_SQL_LIMIT=50

# Security (Change in production)
JWT_SECRET="your-secure-jwt-secret-here"
ADMIN_API_KEY="your-admin-api-key-here"
```

#### 4️⃣ Setup Database Schema

Run the PostgreSQL schema setup:

```bash
npm run setup-db
```

This creates the necessary tables and enables the pgvector extension.

#### 5️⃣ Ingest Document Data

Process and embed the Berkshire Hathaway letters:

```bash
npm run setup-data
```

This command runs three sequential scripts:
1. **`parse-pdfs`**: Extracts text from PDF documents in `data_letters/`
2. **`chunk-documents`**: Splits documents into semantic chunks (saved to `chunks/`)
3. **`ingest-embeddings`**: Generates embeddings and stores them in PostgreSQL

**Expected output:**
```
✅ Parsed 6 PDF documents
✅ Created 342 semantic chunks
✅ Generated and stored 342 embeddings
🎉 Data ingestion complete!
```

#### 6️⃣ Run Development Server

Start the Mastra application:

```bash
npm run dev
```

#### 7️⃣ Access the Mastra Playground

Open your browser and navigate to:

```
http://localhost:8080/agents
```

Try asking questions like:
- "What does Warren Buffett think about cryptocurrency?"
- "How has Berkshire's investment strategy evolved over the past 5 years?"
- "What companies did Berkshire acquire in 2023?"
